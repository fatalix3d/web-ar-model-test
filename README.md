# Skyline Plaza Web AR

Мобильная Web AR-презентация архитектурной GLB-модели. Использует нативный Scene Viewer на Android, Quick Look на iOS и интерактивный 3D-просмотр в остальных браузерах.

## Локальный запуск

```bash
python3 -m http.server 4173
```

Откройте <http://localhost:4173>.

## Публикация

Проект не требует сборки и публикуется из корня ветки `main` через GitHub Pages.
