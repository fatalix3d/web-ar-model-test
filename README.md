# Skyline Plaza Web AR

Мобильная Web AR-презентация архитектурной GLB-модели. Использует нативный Scene Viewer на Android, Quick Look на iOS и интерактивный 3D-просмотр в остальных браузерах.

## Локальный запуск

```bash
python3 -m http.server 4173
```

Откройте <http://localhost:4173>.

## Публикация

Проект не требует сборки и публикуется из корня ветки `main` через GitHub Pages.

## Окружение

Для освещения и отражений используется HDRI [Modern Buildings](https://polyhaven.com/a/modern_buildings) от Greg Zaal / Poly Haven, лицензия CC0.

В корневом узле GLB задан масштаб `0.02`, чтобы нативные AR-просмотрщики открывали макет размером 2% от архитектурного оригинала. Материал фасадного стекла настроен на выраженные отражения и clearcoat.
